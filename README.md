It combines classical grid trading with AI-powered market analysis, adaptive risk management, and real-time web dashboard.> **⚠️ Risk Warning**: Trading cryptocurrencies carries significant risk. This bot can lose money. Use only funds you can afford to lose. Always test with small amounts first.---## Features### Trading- **Spot Grid Trading** — Automated buy-low/sell-high grid strategy- **DCA (Dollar-Cost Averaging)** — Smart entry averaging on drawdowns- **Scalping Engine** — Short-term momentum trades- **AI Advisor** — ML-powered signal confirmation and trend analysis- **Adaptive Risk** — Dynamic position sizing, trailing stops, circuit breakers### Infrastructure- **Zero Circular Imports** — Clean event-driven architecture via `core/events.py`- **Lazy ML Loading** — `sklearn`/`xgboost` load only on first AI call- **Unified Config** — Pydantic v2 validation with env override- **Memory Optimized** — `__slots__` on hot-path classes- **Graceful Shutdown** — Proper SIGTERM/SIGINT handling### DevOps- **Docker Multi-Stage** — Ultra-light image (~400 MB, was 6.8 GB)- **Health Checks** — Docker + nginx + Flask layered checks- **Rate Limiting** — Per-IP and per-user rate limits- **Gzip Compression** — Automatic response compression- **Log Rotation** — Docker json-file driver with limits- **CI/CD** — GitHub Actions: lint, test, security scan, auto-deploy---## Tech Stack| Layer | Technology ||-------|------------|| **Backend** | Python 3.11, Flask,
